# 🧮 LangChain Math Problem Solver and Data Search Assistant

An AI-powered application built with LangChain, OpenAI, and Streamlit that solves mathematical problems, explains reasoning, and searches for factual information using Wikipedia.

## 🚀 Features

- 🧮 **Math Problem Solver:** Solves mathematical calculations using LangChain's LLMMathChain.
- 🧠 **Step-by-Step Reasoning:** Answers logical, reasoning, and general knowledge questions with explanations.
- 🌐 **Wikipedia Search:** Retrieves factual information from Wikipedia.
- 🤖 **AI-Powered Assistant:** Uses OpenAI GPT-4.1-mini to generate responses.
- 💬 **Interactive Chat Interface:** Provides a conversational interface using Streamlit.
- 🔑 **API Key Input:** Allows users to enter their OpenAI API key securely through the sidebar.
- 📜 **Chat History:** Maintains conversation history during the current session.

## 🛠️ Technologies Used

- Python
- LangChain
- OpenAI GPT-4.1-mini
- Streamlit
- Wikipedia API Wrapper
